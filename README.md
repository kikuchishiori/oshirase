# お知らせ

ユーザーごとのログイン、予定、フレンド検索を備えた小さな予定・リマインダーアプリです。

## 起動

Python 3が入ったMacで、プロジェクトフォルダーから実行します。

```sh
python3 server.py
```

ブラウザーで `http://localhost:8000` を開きます。LAN上のスマートフォンから試す場合は、Macとスマートフォンを同じWi-Fiにつなぎ、MacのLANアドレスを使います（例: `http://10.x.x.x:8000`）。

サーバーは停止するとアクセスできません。データは同じフォルダーの `oshirase.sqlite3` に保存されます。削除するとアカウント・予定・フレンド情報も消えるため、必要ならこのファイルをバックアップしてください。

## 保存とユーザー検索

アカウント、認証セッション、予定、フレンド関係、ルーム情報はSQLiteに保存します。予定はログインユーザー単位で分離され、ユーザー検索はこのサーバーに登録したユーザー名を対象にします。ルームは参加者として登録されたユーザーのみが一覧でき、パスワードを確認した後に指定期間内の参加者の予定を取得します。

ルームの予定は日付ごとに表示し、ユーザーを横列、時刻を共通の縦軸として配置します。予定の共有範囲はルームの開始日から終了日までです。

## 公開時の注意

この開発サーバーはTLS/HTTPSを提供しません。HTTPのままインターネットへ公開したり、信頼できないネットワークでパスワードを入力したりしないでください。共有利用にはHTTPS終端、定期バックアップ、適切なサーバー運用が必要です。Teamsから使う場合は、HTTPS対応のホストへアプリとPython APIを一緒にデプロイしてください。HTMLファイルだけを静的ホスティングに置いても、ログイン・検索・サーバー保存APIは動きません。

## Renderへ公開

このフォルダーにはRender Blueprint用の `render.yaml` を用意しています。HTML単体のファイルアップロードではなく、GitHubリポジトリ経由でPythonサーバーごと公開します。

1. GitHubで新しい非公開リポジトリを作り、このフォルダーのファイルをアップロードします。`.gitignore`により、SQLiteデータベースはアップロード対象になりません。
2. Renderで「New」から「Blueprint」を選び、GitHubリポジトリを接続します。
3. Blueprintに表示されるFree Web Serviceを作成します。アプリは`render.yaml`の設定を使って起動します。
4. デプロイ完了後に発行される`https://...onrender.com`のURLを使います。TeamsにはURL全体を登録します。

無料プランを使うため、SQLiteは一時領域の`/tmp/oshirase.sqlite3`に保存されます。登録・ログインは動きますが、無料サービスがスリープから復帰したときや再起動されたときに、アカウント・予定・フレンド・ルームが消えることがあります。これは試用向けの設定です。ローカルのアカウント・予定データは自動移行されないため、公開先でアカウントを作り直してください。
